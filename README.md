# Cãonect 🐾

Plataforma de adoção responsável de pets. Protótipo inicial com React, TypeScript, Vite e PWA.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Publicação

Em **Settings → Pages**, escolha **GitHub Actions**. O workflow publica o site em `https://thiag0ferreira.github.io/caonect/`.

> Dados demonstrativos. Ainda não existe autenticação, banco de dados ou solicitação real de adoção.
